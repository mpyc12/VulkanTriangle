# Vulkan Triangle Project

This project was created while working through the official Khronos Vulkan tutorial. I built the project while reading through the tutorial and learning the concepts behind each stage of Vulkan's rendering process.

## This is NOT original code

This code is based on the official Khronos Vulkan tutorial and was created as a project to showcase my understanding of the API.

I have used this project as a foundation for my other Vulkan projects, such as my Vulkan Template, to help me develop my knowledge of graphics programming.

## I used this project to:

* Learn the fundamentals of how the Vulkan API is structured.
* Develop my existing knowledge of C++.
* Understand how a low-level graphics API works.
* Build a foundation for further Vulkan projects.

This was my first project using an official graphics API. However, I had previously worked with graphics libraries such as **SFML** and **raylib**, which gave me some experience with graphics programming before starting to learn Vulkan.
